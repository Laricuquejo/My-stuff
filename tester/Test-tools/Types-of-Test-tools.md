# Purpose of using tools
- Classification of tools based on the test activities they support:
    - Management tools
    - Static testing tools
    - Test design and implementation tools
    - Test execution and coverage tools
    - Non-functional testing tools
    - DevOps tools
    - Collaboration tools
    - Scalability and deployment standardization tools
    - Other tools

# Purpose of Testing Tools
- Improve the efficiency of the test activities by automating repetitive task or tasks that require significant resources when done manually
- Improve the efficiency of test activities by supporting manual test activities throughout the test process
- Improve the quality of testing activities by allowing for more consistent testing and a higher level of defect reproducibility
- Automate activities that cannot be executed manually
- Increase reliability of testing

# Classification of Tools

- Other tools

# Test Management Tool Features
- Management of tests and test activities
- Scheduling test execution and logging test results
- Linking tests, test results, and defects to requirements or other sources
- Creating reports from various metrics such as number of tests failed, the number of passed tests, number of defects raised, etc.

# Configuration Management Tools
- Store information about versions of the software, test scripts, test cases, test data, and test environments
- Different project assets are usually kept in separete version control systems
- The most commonly used configuration management tool is Git
