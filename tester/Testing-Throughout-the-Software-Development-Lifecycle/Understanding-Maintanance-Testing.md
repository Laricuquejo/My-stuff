# Trigger reasons for maintanance testing:

## Planned changes
### Software enhancements
### Operational and environmental upgrades:
- Example: SQL Server migration to a newer version

### Retirement:
- SW not fit for purpose anymore
- Rewriting the SW using newer tech

### Impact Analysis:
Evaluates the changes made to identify consequences and potential side-effects. You should be ready to answer this questions:
- What has changed?
- Where in the system?
- Which parts are likely to be affected?

### Impact Analysis Challenges:
- Outdated specifications
- Lack of knowledge
- Outdated test cases with no traceability
- Weak or non-existent tools support
