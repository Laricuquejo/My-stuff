# Test Effort Estimation
- Predicts the amount of work to fully complete a test project
- Estimates are not guarantees
- Smaller tasks tend to have more accurate estimates
- Splitting up large tasks can make them easier to estimate

# Estimation Based on Ratios
- Development-to-test effort
- Metrics-based
- Requires historical project data
- Involves calculating standard ratios

# Extrapolation
- Well-suited to iterative SDLCs
- Less effective for initial iterations of new projects 
- Data collection must start as soon as possible
- Outlier iterations can have a large impact on the accuracy
- Some mathematical models can reduce the impact of outliers

 # Planning Poker
 - Variant of Wideband Delphi
 - Commonly used by Agile teams
 - Estimates are made using cards
 - cards may have hours, points or sizes
